# Intake: Owner-only billing

## Input type

client_request

## Source

"The billing page shows what the team pays us. Today any member of the team can open it and read the invoices. Only the
owner of a team should see them; a member who opens the page should be told it is for owners, not shown a broken page."

## Client constraints

- Stack required by the client: the existing one (Vite, React 19, Express 5, PGlite, Vitest)
- Deadline / budget / other: none stated
