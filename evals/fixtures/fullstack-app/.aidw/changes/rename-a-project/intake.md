# Intake: Rename a project

## Input type

client_request

## Source

"People misspell a project name when they create it and there is no way to fix it. The owner of a team should be able to
rename a project from the project's page. Names must stay unique in the team, and a member who is not an owner must be
told they cannot, not left guessing."

## Client constraints

- Stack required by the client: the existing one (Vite, React 19, Express 5, PGlite, Vitest)
- Deadline / budget / other: none stated
