# Intake: Book a slot

## Input type

client_request

## Source

"Patients can see a doctor's days already. Now they should open a day, see its slots, and book a free one without
calling the front desk. If the slots cannot be loaded, say so: last month people thought a doctor had no slots when our
API was down."

## Client constraints

- Stack required by the client: the existing one (Vite, React 19, TypeScript, Vitest)
- Deadline / budget / other: none stated
