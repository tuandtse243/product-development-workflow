# Intake: Owners-only billing

## Input type

client_request

## Source

"Owners should see what the clinic pays us and what is due, on a billing page. Members of the team must not see it, and
neither must anyone who is not signed in. The billing page also has to say when the app runs against Stripe's test
account, so nobody pays a real invoice by mistake while we are still testing."

## Client constraints

- Stack required by the client: the existing one (Vite, React 19, TypeScript, Vitest)
- Deadline / budget / other: none stated
