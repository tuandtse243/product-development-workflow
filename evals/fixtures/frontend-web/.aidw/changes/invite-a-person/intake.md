# Intake: Invite a person

## Input type

client_request

## Source

"Owners should be able to invite a new colleague from the web app: a name and an email, and the colleague gets the
invitation by email. Last time we tried this with the contact form's approach nobody understood which field was wrong,
and some owners clicked twice and the colleague got two emails."

## Client constraints

- Stack required by the client: the existing one (Vite, React 19, TypeScript, Vitest)
- Deadline / budget / other: none stated
