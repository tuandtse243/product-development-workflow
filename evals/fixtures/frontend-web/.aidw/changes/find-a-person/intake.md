# Intake: Find a person

## Input type

client_request

## Source

"Patients keep asking the front desk who the nurse with the red scarf is, or whether Abel still works here. Give the web
app a page where you type a name and see the people of the clinic that match, as you type. People type fast and our
connection to the clinic is slow some mornings, so make sure the page never shows the answer to something the patient
has already typed over."

## Client constraints

- Stack required by the client: the existing one (Vite, React 19, TypeScript, Vitest)
- Deadline / budget / other: none stated
