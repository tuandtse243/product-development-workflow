# Intake: Create a task in a project

## Input type

client_request

## Source

"Team members should be able to add tasks to a project of their team from the API. Only people in the team may add
tasks to its projects. Title and an optional due date for now; assignment comes later."

## Client constraints

- Stack required by the client: the existing one (Express 5, Postgres, TypeScript, Vitest)
- Deadline / budget / other: none stated
