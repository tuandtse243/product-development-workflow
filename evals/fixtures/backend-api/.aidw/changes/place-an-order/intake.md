# Intake: Place an order

## Input type

client_request

## Source

"Team members should be able to order add-ons for their team from the API, and get a confirmation email. Our mail
provider goes down now and then: an order must never be lost because of it, and people should still get their
confirmation once it is back, once."

## Client constraints

- Stack required by the client: the existing one (Express 5, Postgres, TypeScript, Vitest)
- Deadline / budget / other: none stated
