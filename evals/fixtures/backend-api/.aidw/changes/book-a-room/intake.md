# Intake: Book a room

## Input type

client_request

## Source

"Team members should be able to book a meeting room of their team by the hour from the API. When two people grab the
same slot at the same moment, one gets it and the other is told it is taken: never a double booking."

## Client constraints

- Stack required by the client: the existing one (Express 5, Postgres, TypeScript, Vitest)
- Deadline / budget / other: none stated
