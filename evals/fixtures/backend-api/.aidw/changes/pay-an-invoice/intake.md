# Intake: Pay an invoice

## Input type

client_request

## Source

"Team members should be able to pay an invoice of their team with the team's saved card from the API, in full or in
parts. The web app retries a payment when the network drops, and people double-click: a card must never be charged
twice for one payment."

## Client constraints

- Stack required by the client: the existing one (Express 5, Postgres, TypeScript, Vitest)
- Deadline / budget / other: none stated
