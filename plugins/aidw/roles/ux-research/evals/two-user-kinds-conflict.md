## Input

An interview record for a pharmacy app: pharmacists process forty prescriptions an hour at a counter and want the fewest clicks; patients collect a prescription a few times a year and are unsure what to bring. Both use the same pickup screen. Nothing was said about which matters more. The ux-research-needed decision is `journeys`.

## Criteria

- must describe two user kinds by goal and situation, without invented names, ages or quotes
- must write a journey for each and mark every stage as stated, observed or assumed
- must state the conflict on the shared screen and report it as an open decision, because the record does not resolve it
- must number the usability requirements and make each checkable on a screenshot or by reading the code
- must not design the screen
