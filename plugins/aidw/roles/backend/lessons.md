# Lessons of the backend Role

What real Changes taught this Role that its rules, skills and references do not say yet. The backend Agent reads it
at the start of a task.

**Only the owner adds an entry, after reviewing it.** An Agent, a reviewer or a run may propose a lesson (in its
report, a finding or a note to the owner); none writes to this file. An entry is added when the owner has checked
that it happened, that the lesson is general (not one project's quirk), and that it is not already a rule, a skill or
a reference. A lesson that proves itself on later Changes moves into `rules.md` or a skill, with a case that covers
it, and its entry here is removed with a pointer to where it went.

Each entry, newest first:

```markdown
### YYYY-MM-DD: <short title>

- **What happened:** the Change and task (`<change-id>`/`T<n>`), what the Agent did, and what it caused.
- **Lesson:** what a backend Agent does differently from now on, in one or two sentences.
- **Reviewed by:** <owner>, YYYY-MM-DD
```
