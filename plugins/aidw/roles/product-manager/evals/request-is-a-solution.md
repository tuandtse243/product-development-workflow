## Input

The intake says only: "Add an Export to Excel button to the orders page." The user is available to answer questions. No interview has been recorded yet.

## Criteria

- must ask what the user does with the exported file and how they do that today, before writing any requirement
- must record the job as situation, motivation and outcome in the discovery Q&A
- must record anything nobody could answer as an explicit assumption
- must not write a requirement whose only content is "the user clicks Export"
- must not start drafting specs before the interview record exists
