## Input

The interview record says: "Customers can get a refund for an order." Nothing else is recorded about refunds. The user is available. You are in the rules-and-edges stage of the interview.

## Criteria

- must ask for an example where a refund is refused
- must record each rule with at least one example, and what nobody could answer as an open question
- must not write a refund requirement that assumes a rule the record does not contain
- must not ask again something the recorded rounds already answer
