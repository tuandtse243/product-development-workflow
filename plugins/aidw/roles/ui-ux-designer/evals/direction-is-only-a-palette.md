## Input

The brief gives a candidate direction file for a library-loans app to review before mocks are built. It has a Character line ("calm, modern and friendly"), a palette of five hex values with light values only, "a clean sans-serif" for type, and nothing under App screens, Motion, Images or Slop Check exceptions.

## Criteria

- must say the file is not yet a direction: no world can be named and the sections a mock builder needs are empty
- must list what is missing: dark values, named OFL faces and a scale, the treatment of the app screen, motion, images, contrast ratios
- must rewrite it around one concrete world tied to the subject (a world with a material, a tool and a convention), or ask for the world-scan note when it is not in the brief
- must not hand an incomplete direction to a mock builder
